# Ассеты к выгрузке

Figma отдаёт ассеты временными ссылками (≈7 дней) через MCP
(`get_design_context` / `download_assets`). В этой рабочей среде прямой
скачивание по этим ссылкам недоступно (сетевая политика блокирует
`figma.com` для исходящих запросов) — ссылки получены, но byte-контент
не сохранён. Экспортировать реальными файлами при следующей сессии,
где есть доступ, командой `download_assets` по нужному node-id и
сохранить в указанный путь.

## Куда класть файлы

Ассеты лежат в двух местах — статика и тема WordPress несут одинаковую
копию:

* `static/assets/{icons,images,fonts}/`
* `wp-theme/vektor-semi/assets/{icons,images,fonts}/`

Файлы должны совпадать побайтно. Пока ассетов нет, на их местах стоят
заглушки `.asset-pending` с указанием node-id и размера прямо в разметке —
разметку менять не придётся, только заменить заглушку на `<img>`/`<svg>`.

Шрифты Inter (`Inter-Regular/Medium/SemiBold/Bold.woff2`) ждёт
`assets/fonts/`: `fonts.css` и `preload` в теме на них уже настроены,
до выгрузки браузер отдаёт 404 и подставляет системный шрифт.
