# Сайт онлайн-школы по макету Figma

Проект: статическая вёрстка + тема WordPress строго по макету Figma.
Полное ТЗ заказчика — `docs/BRIEF.md`. Аудит макета — `docs/AUDIT.md`.
Карта node-id всех страниц и секций — `docs/FIGMA-NODES.md`.

## Главное правило

**Макет Figma — единственный источник истины.** Нельзя добавлять, удалять
и переставлять блоки, менять тексты, цвета, размеры, отступы, изображения
и навигацию. Если чего-то нет в макете — не придумывать: ставить аккуратный
технический placeholder и дописывать пункт в `docs/AUDIT.md` → «Блокеры».

## Стек

* Статика: HTML5, CSS3, нативный JS. **Без React, Vue, Angular.**
* Сторонние библиотеки — только под элементы, реально присутствующие в макете
  (например слайдер), и только маленькие и стабильные.
* Тема WordPress — классическая, без Elementor, WPBakery и прочих конструкторов.
  Делать **после** того, как статика готова и проверена.

## Как читать макет

Figma подключается по MCP (см. `.mcp.json`). Рабочий цикл:

```
Figma:get_metadata      → структура (только чтобы найти нужный id)
Figma:get_design_context → код секции + ссылки на ассеты
Figma:get_screenshot     → визуальная сверка
```

Важно: `get_design_context` по целой странице не помещается в контекст.
Тянуть **по одной секции** — id брать из `docs/FIGMA-NODES.md`.

Ассеты Figma отдаёт временными ссылками (живут 7 дней). Скачивать сразу
в `static/assets/`, список нужного — `static/ASSETS-TODO.md`.

│   └── FIGMA-NODES.md     карта node-id
├── tools/
│   └── build-preview.py   сборка однофайлового превью
├── preview.html           результат сборки (не редактировать руками)
└── static/
    ├── index.html
    ├── pages/
    └── assets/{css,js,fonts,icons,images}

`static/assets/css/` — `tokens.css`, `base.css`, `fonts.css` и по файлу
на компонент в `components/`. Классы — БЭМ, осмысленные имена.
`block1`, `item2`, `section-new` не использовать.

## Токены

Взяты из макета, менять только вслед за ним. Все значения — в
`static/assets/css/tokens.css`. Ключевое:

* контейнер `1400px`, внутренние поля `32px` (полезная ширина 1336)
* шрифт Inter: 400 / 500 / 600 / 700
* бренд `#7B61FF`, градиент логотипа `135deg, #7B61FF → #00D1FF`
* текст `#0F172B` / `#45556C` / `#62748E`
* границы `#E2E8F0` / `#F1F5F9`, фон подвала `#F8FAFC`
* шапка фиксированная, высота 81px (80 + 1px граница), под ней распорка

## Нерешённые блокеры

Подробно в `docs/AUDIT.md` §5. Коротко:

1. **Мобильных и планшетных макетов в Figma нет** — только desktop.
   Пока не решено, вёрстку писать так, чтобы схлопывание в одну колонку
   добавлялось потом без переписывания разметки.
2. Название бренда расходится: логотип «Вектор семьи», копирайт «Точка роста».
   Верстать как нарисовано, ничего не унифицировать.
3. Нет иконок соцсетей, нет адресов у 13 ссылок подвала, нет экрана для «Войти».
4. Ассеты не выгружены — см. `static/ASSETS-TODO.md`.
5. В OnlineClasses (`1:194`) в макете спроектирован только таб «1–2 класс» —
   для остальных возрастов стоит технический placeholder вместо контента.
6. В TimelineFormat (`1:257`) 7 карточек шагов в макете физически шире
   контейнера (обрезаны overflow-clip) — свёрстаны равной шириной (grid),
   без обрезки контента. Подробности — `docs/AUDIT.md` §5.9.
7. В ResultsFaq (`1:740`) 5 из 6 вопросов FAQ свёрнуты в макете без текста
   ответа (авторский контент отсутствует) — стоит явный placeholder вместо
   выдуманного ответа. Подробности — `docs/AUDIT.md` §5.13.

## Проверка

После каждой секции:

```bash
python3 tools/build-preview.py     # собрать превью
python3 -m http.server 8000 -d static   # посмотреть боевую вёрстку
```

Сверять с макетом через `Figma:get_screenshot` по тому же node-id.
Смотреть: отсутствие горизонтальной прокрутки, чистая консоль, размеры
и отступы совпадают с макетом.

## Формы

Только интерфейс и клиентская валидация. Реальную отправку на почту,
в CRM и внешние сервисы **не подключать** — ни в статике, ни в WordPress.
Новых полей, которых нет в макете, не добавлять.

## Доступность и производительность

Семантика, корректная иерархия заголовков, `alt`, `label`, работа с клавиатуры,
видимый фокус, Escape для модалок, нужные `aria`. Отдельных элементов
доступности, которых нет в макете, в интерфейс не добавлять.

`font-display: swap`, ленивая загрузка картинок ниже первого экрана,
явные размеры у изображений, SVG для векторной графики,
уважать `prefers-reduced-motion`.

Длительность микровзаимодействий 150–400 мс. Запрещены параллакс,
3D-эффекты, вращения, агрессивные масштабирования, свечения.
