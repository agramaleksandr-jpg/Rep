## 1. Страницы

Главная (`1:7` Main Content + слои шапки/подвала `7:1479`/`7:1480`) и
внутренние страницы (курсы, аттестация, о школе, для родителей, блог,

`docs/FIGMA-NODES.md`.

## 2. Токены

Сняты в `static/assets/css/tokens.css`: контейнер 1400/32 (полезная
ширина 1336), Inter 400/500/600/700, бренд `#7B61FF` →
градиент `135deg, #7B61FF → #00D1FF`, текст `#0F172B` / `#45556C` /
`#62748E`, границы `#E2E8F0` / `#F1F5F9`, фон подвала `#F8FAFC`. Шапка
фиксированная, 81px (80 + граница 1px).

Отдельные компоненты используют точечные оттенки, которых нет в общих
токенах (например заголовки карточек Benefits — `#020618`, а не базовый
`--color-text`). Это осознанно: макет использует их только локально,
поэтому они не выносятся в `tokens.css`, а прописаны прямо в CSS
компонента с комментарием.

## 3. Компоненты

`header`, `footer`, `button`, `hero`, `benefits`, `online-classes`,
`timeline-format` — готовы и сверены со
скриншотами макета. Общие паттерны:

* секция = `padding-block` + `.container` с текстовым блоком по центру
  и контентной сеткой ниже;
* карточки — `border` + `border-radius` + мягкая тень, иконка в цветной
  плашке 48×48 (radius 16) с SVG 24×24 внутри;
* `.reveal` (см. `base.css` + `main.js`) — плавное появление блоков ниже
  первого экрана при прокрутке, отключается при `prefers-reduced-motion`.

## 4. Формы и интерактив

Модалка консультации (ловушка фокуса, Escape), маска телефона,
клиентская валидация без реальной отправки — см. `main.js`.

## 5. Блокеры

1. **Адаптив.** В Figma только desktop-макет (мобильных/планшетных нет).
   Решение отложено: секции вёрстаются на `grid`/`flex` с относительными
   единицами, чтобы схлопывание в одну колонку добавилось позже без
   переписывания разметки.
2. **Название бренда расходится.** Логотип — «Вектор семьи», копирайт
   подвала — «Точка роста». Не унифицировать, верстать как нарисовано.
3. **Иконки соцсетей.** В подвале три кружка без иконок и без ссылок —
   верстаются как есть (`footer__social-item`), контент добавится, когда
   появится в макете.
4. **Ассеты не выгружены.** Полный список — `static/ASSETS-TODO.md`.
   Причина: временные ссылки Figma на экспорт (~7 дней) недоступны для
   прямого скачивания из текущей рабочей среды (сетевая политика
   блокирует исходящие запросы к `figma.com`); сами ссылки и node-id
   получены и записаны, остаётся скачать при наличии доступа. До тех пор
   — технический placeholder `.asset-pending` (описан в `base.css`,
   исчезнет вместе с заглушками, когда появятся реальные ассеты).
5. **Адреса ссылок подвала.** 13 из 17 ссылок ведут на реальные разделы,
   остальные — заглушка `href="#"` (нет соответствующих экранов в
   макете).
6. **Экран «Войти».** Целевой URL/страница не определены в макете —
   ссылка временно ведёт на `#`.
7. **Шрифты Inter.** `.woff2`-файлы не выгружены из макета; `fonts.css`
   уже описывает нужные `@font-face`, файлы подложить в
   `assets/fonts/` при выгрузке.
8. **OnlineClasses (`1:194`) — контент только для одного таба.** В Figma
   у переключателя возрастов спроектирована содержательная панель лишь
   для «1–2 класс» (`1:212` Tab Panel); слоёв с контентом для «3-4»,
   «5-9» и «10-11 класс» в файле нет — только сами вкладки-кнопки.
   Верстать без выдумывания текста/цены/фото для недостающих групп:
   вкладки переключаются (клик + стрелки, ARIA tablist/tab/tabpanel),
   но их панели показывают техническую заглушку
   «Материалы для … класса ещё не добавлены в макет Figma». Обновить,
   когда заказчик дорисует остальные состояния.
9. **TimelineFormat (`1:257`) — карточки шагов шире контейнера.** 7 карточек
   шага зафиксированы в макете по 200px + зазор 16px = 1496px, а контейнер
   контента — 1336px (перекрытие 160px, в Figma обрезано `overflow-clip`,
   из-за чего 7-й шаг «Аттестация» не виден целиком). Сами карточки при этом
   помечены в Figma как гибкие (`flex-grow`, равный вес у всех семи) — то
   есть замысел автора «поровну заполнить строку», а 200px это лишь снимок
   при той ширине холста, на которой их рисовали. Свёрстано по замыслу:
   `grid-template-columns: repeat(7, 1fr)`, все 7 шагов видны полностью,
   ничего не обрезается. Декоративная соединительная линия под карточками
   перенесена как есть (в макете почти не видна — карточки её перекрывают).
10. **Шрифт Inter Black (900).** Понадобился только для фоновых цифр шагов
    TimelineFormat; `.woff2`-файл ещё не выгружен (тот же блокер 5.7, теперь
    актуален для двух начертаний).
