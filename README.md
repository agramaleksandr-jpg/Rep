# Игралочка

Детская игра для телефона (PWA, горизонтальная ориентация): монстрики, карта, стройка дома и сада, 10 мини-игр по 5 уровней. Вся озвучка записана заранее (нейросетевой голос Silero) и работает без интернета.

Как установить на телефон: открыть ссылку GitHub Pages в Chrome (Android) или Safari (iPhone), затем «Добавить на главный экран».

- `index.html`, `sw.js`, `manifest.webmanifest`, `voice-*.js`, иконки — готовая игра.
- `source/` — исходники и скрипты сборки (`build.py`, `pwa.py`, `source/voice/`).

Озвучка: модель Silero v4 (лицензия только для некоммерческого использования).
