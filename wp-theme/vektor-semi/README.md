# Тема WordPress «Вектор семьи»

Классическая тема (без Elementor, WPBakery и прочих конструкторов),
собранная из готовой статики `static/`. Разметка, классы и CSS взяты
из статики без изменений — темплейты только подставляют данные из WordPress
в те же самые блоки.

## Установка

1. Скопировать папку `vektor-semi` в `wp-content/themes/`.
2. «Внешний вид → Темы» → активировать «Вектор семьи».
3. Пройти по шагам настройки ниже — без них часть шаблонов покажет
   пустые списки (это не ошибка темы, просто в базе ещё нет контента).

## Обязательная настройка после активации

### Меню

«Внешний вид → Меню». В теме четыре области:

| Область                  | Где выводится            | Пункты по макету                                                    |
| ------------------------ | ------------------------ | ------------------------------------------------------------------- |
| `primary`                | шапка                    | Курсы, Аттестация, О школе, Для родителей, Блог, Контакты            |
| `footer_learning`        | подвал, «Обучение»       | 4 пункта                                                            |
| `footer_info`            | подвал, «Информация»     | 5 пунктов                                                           |
| `footer_docs`            | подвал, «Документы»      | 4 пункта                                                            |

Адреса 13 ссылок подвала в макете не заданы (блокер 5.3 в `docs/AUDIT.md`) —
их проставляет заказчик при заполнении меню.

Пункт текущей страницы получает `aria-current="page"` автоматически
(фильтр `nav_menu_link_attributes` в `inc/setup.php`).

### Страницы и шаблоны

Создать страницы и назначить им шаблон в блоке «Свойства страницы»:

| Страница         | Шаблон                          | Соответствие в статике        |
| ---------------- | ------------------------------- | ----------------------------- |
| Аттестация       | «Аттестация»                    | `pages/attestation.html`      |
| О школе          | «О школе»                       | `pages/about.html`            |
| Для родителей    | «Для родителей»                 | `pages/parents.html`          |
| Контакты         | «Контакты»                      | `pages/contacts.html`         |

Главная и блог — «Настройки → Чтение»: «Главная страница» → статическая
главная (любая пустая страница, содержимое берётся из `front-page.php`),
«Страница записей» → страница «Блог».

### Курсы

Тема регистрирует свой тип записи:

* тип записи `vs_course`, архив по адресу `/courses/` — это страница
  «Архив курсов» из макета (`pages/courses.html`);
* таксономия `vs_course_group` — плашка-тег на карточке курса
  («Начальная школа», «Средняя школа» и т. д.);
* поля курса в метабоксе «Параметры курса»: возраст, формат, старт,
  длительность, куратор, стоимость.

Одиночный курс (`single-vs_course.php`) — это `pages/course.html` из макета.
Архив курсов выводит все курсы без пагинации: в макете нарисованы
6 карточек и переключателя страниц нет.

### Контакты в шапке и подвале

Телефон, e-mail и график работы редактируются в «Настройки → Общие»
(поля добавлены темой). Значения по умолчанию — из макета.

### Название школы

В макете логотип подписан «Вектор семьи», а копирайт в подвале —
«Точка роста» (блокер 5.2, верстали как нарисовано). В теме копирайт берётся
из «Настройки → Общие → Название сайта», так что расхождение снимается
без правки шаблонов — заказчику достаточно указать нужное название.

### Виджеты

Область «Боковая колонка блога» — правая колонка на странице блога.
Если виджетов нет, показывается карточка подписки из макета.

## Структура

```
vektor-semi/
├── style.css                 манифест темы (правил нет, стили в assets/css)
├── functions.php             константы + подключение inc/*
├── inc/
│   ├── setup.php             поддержка возможностей, меню, размеры картинок
│   ├── enqueue.php           стили и скрипты (adaptive.css — последним)
│   ├── post-types.php        тип записи vs_course, таксономия, метабокс
│   └── template-tags.php     вспомогательные функции вывода
├── header.php / footer.php   шапка и подвал по макету
├── front-page.php            главная — 7 секций через get_template_part
├── template-parts/
│   ├── sections/             7 секций главной
│   └── blocks/               модалка, карточка курса, карточка статьи, подписка
├── page-templates/           4 шаблона внутренних страниц
├── archive-vs_course.php     каталог курсов
├── single-vs_course.php      страница курса
├── home.php / single.php     блог и статья
├── page.php / index.php / search.php / searchform.php / 404.php
└── assets/                   копия css/js из static/assets
```

## Стили

`inc/enqueue.php` повторяет принцип статики: базовый набор
(`fonts` → `tokens` → `base`) грузится всегда, компонентные файлы —
по типу текущего шаблона, `adaptive.css` — последним.

Ассеты (иконки, фотографии, шрифты Inter) из макета ещё не выгружены —
см. `static/ASSETS-TODO.md`. Пока на их местах стоят технические
заглушки `.asset-pending`; когда файлы появятся в `assets/`, разметку
править не придётся.

## Формы

Все формы — интерфейсные: разметка, маска телефона и клиентская валидация.
Реальная отправка на почту, в CRM и внешние сервисы по ТЗ не подключается
ни в статике, ни в теме.
